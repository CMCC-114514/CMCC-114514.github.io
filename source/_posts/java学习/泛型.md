## 简介

泛型用于约束集合中元素的数据类型，并进行检查

泛型只能使用引用数据类型（对于基本数据类型，需要使用其包装类）

泛型统一了集合元素的数据类型，同时将避免了程序异常，当不确定存储数据的类型时，就可以使用泛型

## 泛型定义

泛型可以在多个位置定义：

1. 在类上定义

```java
public class Class1<E> {
    // 类的成员变量和成员方法
}
```

其中，`<E>` 是类型形参，可以自己定义参数名，如 `<type>`

在创建泛型类的对象时，就需要传入类型形参的值（不能是基本数据类型）：

```java
Class1<Integer> class1 = new Class1<>();
```

在泛型类中，也可以使用类型形参作为成员变量的类型或成员方法的参数类型：

```java
public class Class2<E> {
    private E element;

    public boolean setElement(E e) {
        this.element = e;
        return true;
    }

    public E getElement() {
        return element;
    }
}
```

2. 在方法上定义

```java
public static <E> void test(E e) {
    // 方法体
}
```

虽然在泛型类中，可以直接使用类型形参作为方法的参数类型，但是实际情况有可能是“只有个别方法的参数类型是不确定的”，所以我们直接在方法上定义泛型，这样子定义的泛型只能在该方法中使用

泛型方法的调用与普通方法无异：

```java
public static void main(Strings[] args) {
    String s = "str";
    test(s);

    int i = 99;
    test(i);
}
```

3. 在接口上定义

```java
public interface Inter1<E> {
    // 接口主体
}
```

泛型接口的实现类需要指定类型形参 `<E>` 的具体值，否则需要实现为泛型类并在创建对象时指定类型：

```java
public class Impl1 implements Inter1<String> {
    // 实现为普通类
}

public class Impl2<E> implements Inter1<E> {
    // 实现为泛型类
}
```

## 泛型的继承

泛型是不具备继承性的，当泛型类 `Test<E>` 的类型形参分别被指定为类 `Class1` 和类 `Class2` ，变为 `Test<Class1>` 和 `Test<Class2>` 时，无论 `Class1` 与 `Class2` 是否存在继承关系，这两个泛型类都相互独立，互不相关

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Grand> listofGrand = new ArrayList<>();
        ArrayList<Father> listofFather = new ArrayList<>();
        ArrayList<Son> listofSon = new ArrayList<>();

        method(listofGrand);
        method(listofFather);    // 报错
        method(listofSon);        // 报错
       
        /*
        这里会报错的原因是，
        ArrayList<Grand>、ArrayList<Father>、ArrayList<Son>
        是三个不同的类，而且之间没有继承关系
         */
    }

    // 使用传入的参数与泛型有关的方法做演示
    public static void method(ArrayList<Grand> grands) {
        System.out.println("grand");
    }
}

// 三个类及其继承关系
class Grand {}
class Father extends Grand {}
class Son extends Father {}
```

但如果我们需要传递类型形参E及其父类（或子类）而不希望传递其他类，我们就需要使用泛型通配符

### 泛型通配符

  通配符使用 `?` 表示，有两种形式：

1. `? extends E` ：传递E及其子类

2. `? super E`：传递E及其父类

```java
public class Main {
    // 传递类型形参为 Grand 及其子类的泛型类对象
    public static void method1(ArrayList<? extends Grand> grands) {
        System.out.println("Grand and extends");
    }

    // 传递类型形参为 Son 及其父类的泛型类对象
    public static void method2(ArrayList<? super Son> sons) {
        System.out.println("Son and super");
    }
}
```

通配符可以限定类型参数的范围，防止无关类传入
