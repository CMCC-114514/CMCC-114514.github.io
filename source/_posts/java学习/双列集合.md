## 键值对 Entry

- 键值（key, value）对是双列集合的基本单元，也就是说，双列集合一次需要添加一对数据（ `key` 与 `value`）

- 键值对中，`key` 不可以重复，但是 `value` 可以重复

- `key` 和 `value` 是一一对应的关系

双列集合的结构如下：

| key | value |
|:---:|:-----:|
| 可乐  | 3元    |
| 雪碧  | 3元    |
| 芬达  | 3.5元  |

## Map 集合

`Map` 集合是所有双列集合的父接口，所有的双列集合都实现了 `Map` 接口

`Map` 有以下常见的成员方法：

```java
public class Main {
    public static void main(String[] args) {
        Map<String, Double> menu = new HashMap<>();
        menu.put("可乐", 3.0);            // 添加键值对，重复的键值对会被覆盖
        menu.remove("可乐");              // 通过键移除键值对，也可以输入完整的键值对
        menu.containsKey("雪碧");         // 是否存在键
        menu.containsValue(15.0);        // 是否存在值
        int size = menu.size();          // 返回集合长度 
        menu.clear();                    // 清除集合
        menu.isEmpty();                  // 集合是否为空
    }
}
```

### 遍历

`Map` 可以通过键遍历值，步骤如下：

1. 通过 `keySet()` 方法获取键集合 `keys`

2. 遍历 `keys` ，然后通过 `get()` 方法获取 `value` 

示例：

```java
public class Main {
    public static void main(String[] args) {
        Random rand = new Random();
        Map<String, Integer> map = new HashMap<>();

        for (int i = 0; i < 20; i++) {
            int r = rand.nextInt(100);
            map.put("test" + r, r);
        }

        Set<String> keys = map.keySet();        // 通过 keySet() 方法获取键集合
        for (String key : keys) {               // 通过 key 遍历 value
            System.out.println(key + "->" + map.get(key));
        }

        // 也可以使用迭代器遍历
        Iterator<String> keyIt = keys.iterator();
        while (keyIt.hasNext()) {
            String key = keyIt.next();
            System.out.println(key + "->" + map.get(key));
        }

        // 也可以使用 forEach() 方法 + lambda表达式遍历
        keys.forEach((key) -> System.out.println(key + "->" + map.get(key)));
    }
}
```

`Map` 也可以直接遍历键值对对象，步骤如下：

1. 通过 `entrySet()` 方法获取键值对集合 `entries`

2. 通过键值对对象的 `getKey()` 方法和 `getValue()` 方法获取 `key` 和 `value`

示例：

```java
public class Main {
    public static void main(String[] args) {
        
        /*创建Map对象*/

        Set<Map.Entry<String, Integer>> entries = map.entrySet();       // 获取键值对集合
        for (Map.Entry<String, Integer> entry : entries) {              // 遍历集合
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }

        // 也可以通过迭代器遍历
        Iterator<Map.Entry<String, Integer>> iterator = entries.iterator();
        while (iterator.hasNext()) {
            Map.Entry<String, Integer> entry = iterator.next();
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }

        // 也可以通过 forEach() 方法遍历
        entries.forEach(entry -> System.out.println(entry.getKey() + ": " + entry.getValue()));
    }
}
```

`Map` 还可以直接使用 `forEach()` 方法遍历：

```java
public class Main {
    public static void main(String[] args) {
        
        /*创建Map对象*/

        // 使用 forEach() 方法遍历，使用lambda表达式
        map.forEach((k,v) -> System.out.println(k + "->" + v));
    }
}
```
