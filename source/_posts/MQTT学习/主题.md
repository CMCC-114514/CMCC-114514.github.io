 ## 简介

从本质上来说，MQTT的主题就是一个 UTF-8 编码的字符串，用于给消息进行分类

我们也可以指定多层主题，每层主题之间使用 `/` 分隔，如 `chat/topic1/msg1`

MQTT 的主题在客户端订阅或发布信息时自动创建，不需要手动进行创建

## 主题通配符

主题通配符有两种： `+` 和 `#` ，它们的作用是帮助客户端一次订阅多个主题

### 单层通配符 `+`

单层通配符用于替代订阅的主题中的某个层级，有效的用法如下：

```
+				（直接使用）
topic/+			（作为主题的最后一个字符）
topic/+/msg		（替代某一个层级）
```

客户端按以上方式订阅主题后，就会收到匹配的格式的主题的消息

举个例子，假设发送端发送以下主题的信息：

```
topic/chat1/msg
topic/chat2/msg
topic/chatSp/msg
topic/fromMIKU/msg
topic/holy/shit
```

如果客户端订阅主题 `topic/+/msg` ，因为前四个主题的格式均与订阅主题的格式匹配，所以客户端就会接收到前四个主题的信息，而不会接收到最后一个主题的信息

### 多层通配符 `#`

多层通配符用于替代订阅主题的所有子层级，有效的用法如下：

```
#			（直接使用）
topic/#		（作为主题的最后一个字符）
```

客户端按以上方式订阅主题后，就会收到匹配的格式的所有主题的消息

举个例子，如果客户端订阅了主题 `topic/#` ，那么之前例子中的所有五个消息都会匹配，所以客户端就会接收到所有主题的信息

## 系统主题

以 `$SYS` 开头的主题就是系统主题，其作用为获取 MQTT 服务器自身运行状态，如集群状态、客户端上线与下线、客户端订阅、IP地址等信息

EMQX通常不允许客户端自行订阅系统主题，但是我们可以通过修改权限来订阅主题，过程略

EMQX官方文档关于系统主题的部分见 [系统主题 | EMQX 企业版 文档](https://docs.emqx.com/zh/emqx/latest/observability/mqtt-system-topics.html#%E7%B3%BB%E7%BB%9F%E4%B8%BB%E9%A2%98)
